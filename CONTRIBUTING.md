# Contributing

Issues are welcome: bugs, crashes, and screens that behave differently from
the Android game. Please use the bug report form and attach the logs from a
diagnostics build (the README says how to make one).

**This repository is generated.** Development happens upstream, and each
release replaces the tree here in one commit. A pull request cannot be merged
as-is, because the next release would overwrite it. Open one anyway if you
have a fix: it will be applied upstream, credited, and arrive with the next
release.
